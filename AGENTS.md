# Repository guidance

When creating wireframes or prototypes, read `PROTOTYPE_DEFAULTS.md` and follow those defaults unless the user specifies otherwise.

## Render approval

When Ivan says **Render** for a queued item, follow [the Render approval workflow](.agents/skills/render-approval/SKILL.md). Treat Render as approval of that item's exact scope only; it does not authorize implementation. Keep the queue, handoff and spec consistent, and do not report approval as recorded until the Git-tracked record has been updated. A separate **Build** instruction is required before implementation.
